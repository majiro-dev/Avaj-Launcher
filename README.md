# Avaj-Launcher
## Overview
Avaj Launcher is a Java-based simulation program that models the movement of aircraft in a virtual environment. It follows Object-Oriented Programming (OOP) principles and is designed to reinforce understanding of UML diagrams, design patterns, and Java development.

## Features
-Simulates various aircraft (balloons, jets, helicopters) following predefined flight rules.
-Uses a weather tower to update aircraft based on real-time weather changes.
-Implements Observer design pattern to manage aircraft and weather interactions.
-Reads scenario input from a file and logs simulation results to simulation.txt.
